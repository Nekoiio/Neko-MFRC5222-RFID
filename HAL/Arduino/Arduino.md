# ArduinoSPIBus

## Description

Arduino implementation of SPIBus.

Uses the Arduino SPI library.

---

## Constructor

```cpp
ArduinoSPIBus(uint8_t chipSelectPin)
```
## Input
| Parameter     | Description                     |
| ------------- | ------------------------------- |
| chipSelectPin | Pin connected to MFRC522 SDA/SS |

## Output
Creates SPI bus object.
